# 小红书音乐剧首演 Repo 舆情

用于小红书音乐剧首演舆情采样、筛除返场和粉丝内容、分析剧目口碑及标记疑似侵权。包含采样规则、报告模板和 Word 交付指南。

## 在 Codex 安装

将此 GitHub 仓库中 `skills/xhs-musical-premiere-repo` 文件夹的链接发给 Codex，并说“用 skill-installer 安装这个 GitHub Skill”。也可以下载仓库，将整个 `xhs-musical-premiere-repo` 文件夹复制到 `~/.agents/skills/`，然后打开新的 Codex 聊天。

安装后可以说：

> 使用 $xhs-musical-premiere-repo，整理《剧目名》首演后 48 小时内的小红书 repo 舆情，区分有效剧评、粉丝返场内容和疑似侵权。

## 数据来源和 Word 导出

- 直接采集时，可使用已登录的小红书浏览器或自行配置并登录的小红书 MCP。也可提供已采集的笔记供分析。
- 安装包仅包含技能说明和参考文件。小红书 MCP、登录状态及内部报告模板需各自准备。
- 导出 Word 需要可用的文档工具。需要定制页眉时，请提供 Word 模板或 Logo。
